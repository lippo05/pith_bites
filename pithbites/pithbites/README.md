# Pith Bites website

Fibre-enriched cookies made with upcycled durian pith. Customers add packs to the cart and send the order on Instagram (@Pith_Bites).

## Files
- `index.html` – page content
- `style.css` – design
- `script.js` – cart, flavour tabs, Instagram order button
- `images/` – all photos used by the page (linked as `images/name.jpg`)

## Run on your computer
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a new repository on GitHub and upload all files, keeping `images/` as a folder next to `index.html`.
2. Go to Settings > Pages.
3. Under "Build and deployment", choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. After a minute, your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Change a photo
Replace the file in `images/` with a new one of the same name, or change the name in `index.html`.
